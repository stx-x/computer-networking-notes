# 习题

## 复习题

### 1.1 节

**R1.** 主机与端系统有什么区别？列举若干不同类型的端系统。Web 服务器是端系统吗？

**R2.** **协议**一词常用于描述外交关系。ChatGPT 会如何描述外交协议？

**R3.** 为什么标准对协议很重要？

### 1.2 节

**R4.** 列举四种接入技术，并把每一种归类为家庭接入、企业接入或广域无线接入。

**R5.** HFC 的传输速率是用户专用的还是共享的？HFC 下行信道中可能发生碰撞吗？为什么？

**R6.** 列举你所在城市可用的居民接入技术。对每种接入，给出其标称下行速率、上行速率和月费。

**R7.** 以太网局域网的传输速率是多少？

**R8.** 以太网可以运行在哪些物理媒体上？

**R9.** HFC、DSL、FTTH、FWI 和 LEO 卫星都用于居民接入。对每种接入技术，给出其传输速率范围，并说明其传输速率是共享的还是专用的。

**R10.** 描述当今最流行的无线因特网接入技术，并比较它们的异同。

### 1.3 节

**R11.** 假设发送主机与接收主机之间只有一台分组交换机，发送主机到交换机、交换机到接收主机之间的传输速率分别为 $R_{1}$ 和 $R_{2}$。假定交换机采用存储转发分组交换，发送一个长度为 $L$ 的分组的总端到端时延是多少？（忽略排队时延、传播时延和处理时延。）

**R12.** 电路交换网相对于分组交换网有什么优点？在电路交换网中，TDM 相对于 FDM 有什么优点？

**R13.** 假设用户共享一条 2 Mbps 的链路，每个用户在发送时以 1 Mbps 连续发送，但只有 20% 的时间在发送（参见 1.3 节关于统计复用的讨论）。

+ 若采用电路交换，能支持多少个用户？
  + 对本问题余下部分，假设采用分组交换。为什么在同时发送的用户不超过两个时，链路之前基本上不会产生排队时延？为什么三个用户同时发送时就会产生排队时延？
  + 求某给定用户正在发送的概率。
  + 假设现在有三个用户，求在任一时刻三个用户同时发送的概率，并求队列增长的时间比例。

**R14.** 为什么层次结构中同一层的两个 ISP 常常互相对等？IXP 如何赚钱？

**R15.** 一些内容提供商建立了自己的网络。请描述谷歌的网络。内容提供商建立这些网络的动机是什么？

### 1.4 节

**R16.** 考虑一个分组经一条固定路由从源主机发往目的主机。列出端到端时延的各个组成部分。其中哪些时延是固定的，哪些是可变的？

**R17.** 访问配套网站上"传输时延与传播时延"交互式动画。在动画提供的速率、传播时延和分组长度中，找出一组参数，使发送方在分组的第一个比特到达接收方之前就已完成发送；再找出另一组参数，使分组的第一个比特在发送方完成发送之前就到达接收方。

**R18.** 一个长度为 1000 字节的分组，在距离 2500 km、传播速度 $2.5 \times 10^{8}$ m/s、传输速率 2 Mbps 的链路上传播需要多长时间？更一般地，一个长度为 $L$ 的分组在距离为 $d$、传播速度为 $s$、传输速率为 $R$ bps 的链路上传播需要多长时间？这个时延与分组长度有关吗？与传输速率有关吗？

**R19.** 假设主机 A 要向主机 B 发送一个大文件。从 A 到 B 的路径有三条链路，速率分别为 $R_{1} = 500$ kbps、$R_{2} = 2$ Mbps、$R_{3} = 1$ Mbps。

+ 假设网络中没有其他流量，该文件传送的吞吐量是多少？
  + 假设文件为 400 万字节。用该吞吐量粗略计算把文件传送到 B 需要多长时间？
  + 重复 (a) 与 (b)，但把 $R_{2}$ 改为 100 kbps。

**R20.** 假设端系统 A 要向端系统 B 发送一个大文件。请从很高层次上描述端系统 A 如何由该文件生成分组。当其中一个分组到达路由器时，路由器利用分组中的什么信息来确定把该分组转发到哪条链路上？为什么说因特网中的分组交换类似于"从一个城市开车到另一个城市、沿途问路"？

**R21.** 访问配套网站上的"排队与丢包"交互式动画。最大发送速率和最小发送速率分别是多少？在这些速率下，流量强度分别是多少？用这些速率运行动画，确定丢包发生需要多长时间；然后再次重复该实验，看丢包又需要多长时间。两次的数值相同吗？为什么？

### 1.5 节

**R22.** 列举一个层可以执行的五项任务。是否可能由两层（或更多层）来完成其中某一项（或几项）任务？

**R23.** 因特网协议栈有哪五层？各层的主要职责是什么？

**R24.** 什么是应用层报文？什么是运输层报文段？什么是网络层数据报？什么是链路层帧？

**R25.** 在因特网协议栈中，路由器处理哪几层？链路层交换机处理哪几层？主机处理哪几层？

说明：原书本章还给出 32 道计算与分析题（P1–P32，原书第 62–67 页），涵盖接入网速率计算、存储转发时延、流量强度与排队、端到端吞吐量、分层与封装等。这些题目与正文各节的公式一一对应，建议配合本节复习题一并练习。

# 附录 B　符号与公式速查

| 术语 | English |
| --- | --- |
| $L$ | [分组长度（比特）] |
| $R$ | [链路传输速率（比特/秒）] |
| $N$ | [源到目的之间的链路数（因而有 $N - 1$ 台路由器）] |
| $d$ | [两台路由器之间的距离（米）] |
| $s$ | [链路的传播速度（米/秒），约 $2 \times 10^{8}$～$3 \times 10^{8}$] |
| $a$ | [分组到达队列的平均速率（分组/秒）] |
| $F$ | [文件长度（比特）] |

| **公式** | **说明** |
| --- | --- |
| 传输时延 | 传播时延 |
| 节点时延 | 存储转发端到端时延 |
| 端到端时延 | 排队时延的关键参数，应 $\le 1$ |
| 两链路网络的吞吐量 | 多链路网络的吞吐量 |
| 文件传送的平均吞吐量 | 大文件传送时间估计 |
