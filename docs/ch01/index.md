今天的因特网大概是有史以来人类建造的最庞大的工程系统：数亿台互联的计算机、通信链路和交换机；数十亿通过笔记本电脑、平板电脑和智能手机上网的用户；还有形形色色的新型联网"物"——游戏机、监控系统、手表、眼镜、恒温器、机器人、汽车，甚至尿布。面对如此庞大、组件如此繁多、用途如此多样的因特网，我们还有希望理解它的工作原理吗？是否存在一些指导性的原理和结构，可以作为理解这样一个惊人庞大而复杂系统的基础？如果有，学习计算机网络是否可能既有趣又好玩？幸运的是，这些问题的答案都是响亮的"是"！本书的目标正是为你提供一个关于计算机网络这一动态领域的现代导论，给你理解今天的网络——以及明天的网络——所需的原理与实践洞见。

本章对计算机网络与因特网作一个全景式概览，目的是描绘一幅宏观图景，为全书设定语境，做到"见森林而不只见树木"。这一导论性章节将涉及大量内容、讨论网络的许多组成部分，同时不迷失大局。

本章的组织方式如下：在介绍一些基本术语和概念之后，先考察构成网络的基本硬件与软件组件——从网络边缘开始，看端系统和运行在其中的网络应用；然后探索计算机网络的核心，考察传输数据的链路与交换机，以及把端系统连接到网络核心的接入网与物理媒体；我们会认识到因特网是"网络的网络"，并了解这些网络如何互连。

完成对网络边缘与核心的概览之后，本章后半部分将采取更宏观、更抽象的视角：考察计算机网络中数据的时延、丢包与吞吐量，并给出端到端吞吐量和时延的简单定量模型（这些模型考虑传输时延、传播时延和排队时延）；随后介绍计算机网络中的若干关键体系结构原理，即协议分层与服务模型；还会了解到计算机网络易受多种攻击，概览其中一些攻击并思考如何使网络更安全；最后以一段简短的计算机网络发展史收束全章。
