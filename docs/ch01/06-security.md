# 1.6　面对攻击的网络

今天的因特网对许多机构（大大小小的公司、大学、政府机构）而言已成为关键任务系统，许多个人的职业、社交与私人活动也依赖因特网；还有数十亿"物"（可穿戴设备、家用设备等）正接入因特网。但在这一切便利与兴奋背后，还有一个阴暗面：在那里，"坏人"试图通过破坏我们联网的计算机、侵犯我们的隐私、让我们赖以生存的因特网服务瘫痪，来搅乱我们的日常生活。

**网络安全**这一领域，研究的正是坏人如何攻击计算机网络，以及我们这些即将成为网络专家的人如何防御这些攻击，或者更好的是，从一开始就设计出对这类攻击免疫的新体系结构。鉴于现存攻击之频繁、种类之繁多，以及未来更新、更具破坏性攻击之威胁，网络安全已成为计算机网络领域的核心议题。本书的特色之一，就是把网络安全问题推到前台。

由于我们尚未具备计算机网络与因特网协议的专业知识，这里先概览当今较为普遍的一些安全问题，为后续章节更实质性的讨论做个铺垫。因此我们只问：可能出什么问题？计算机网络为何脆弱？当今较常见的攻击有哪些？

## 恶意软件：坏人可经由因特网把恶意软件植入你的主机

我们把设备接入因特网，是为了收发数据——其中包括各种好东西：Instagram 帖子、搜索结果、流媒体音乐、视频会议、在线电影等等。但不幸的是，伴随这些好东西而来的还有恶意的东西——统称**恶意软件**（malware），它们也能进入并感染我们的设备。恶意软件一旦感染设备，就能干各种坏事：删除我们的文件；安装**间谍软件**收集我们的隐私信息（如社会安全号、口令、击键记录），再把这些信息（当然是通过因特网！）发回给坏人。被攻陷的主机还可能被编入一个由成千上万台同样被攻陷的设备组成的网络——统称**僵尸网络**（botnet）——坏人控制并利用它来分发垃圾邮件，或对目标主机发起**分布式拒绝服务攻击**（稍后讨论）。

今天很多恶意软件是**自我复制**的：一旦感染一台主机，它就从该主机出发，经由因特网寻找进入其他主机的途径；再从新感染的主机出发，继续寻找更多主机。这样，自我复制的恶意软件可以指数式快速传播。

## 拒绝服务攻击：坏人可攻击服务器与网络基础设施

另一大类安全威胁称为**拒绝服务**（denial-of-service, DoS）攻击。顾名思义，DoS 攻击使合法用户无法使用某个网络、主机或其他基础设施。Web 服务器、邮件服务器、DNS 服务器（第 2 章讨论）以及机构网络都可能遭受 DoS 攻击。多数因特网 DoS 攻击可归入以下三类之一：

::: tip 要点

+ **漏洞攻击**（vulnerability attack）：向目标主机上运行的有漏洞的应用或操作系统发送少数精心构造的报文。如果把正确的分组序列发送给有漏洞的应用或操作系统，服务可能停止，更糟的是主机可能崩溃。
  + **带宽洪泛**（bandwidth flooding）：攻击者向目标主机发送海量分组，多到把目标的接入链路堵塞，使合法分组无法到达服务器。
  + **连接洪泛**（connection flooding）：攻击者在目标主机上建立大量半开或完全打开的 TCP 连接（TCP 连接见第 3 章）。主机可能被这些虚假连接拖垮，以致不再接受合法连接。

:::

现在更详细地探讨带宽洪泛攻击。回想 1.4.2 节关于时延与丢包的分析可知：若服务器的接入速率为 $R$ bps，则攻击者需要以约 $R$ bps 的速率发送流量才能造成损害。若 $R$ 很大，单个攻击源可能无法产生足够流量来伤害服务器；而且，如果所有流量都来自单一源，上游路由器或许能检测到该攻击并在流量接近服务器之前封锁该源的全部流量。在**分布式拒绝服务**（DDoS）攻击中（如图 1.26 所示），攻击者控制多个源，让每个源都向目标猛烈发送流量。这样，所有受控源的流量速率之和需达到约 $R$ 才能使服务瘫痪。利用由成千上万台被攻陷主机构成的僵尸网络发起 DDoS 攻击，在今天屡见不鲜。DDoS 攻击比来自单一主机的 DoS 攻击难检测、难防御得多。每年针对因特网基础设施的大型 DDoS 攻击大约有 100 起 [Sitaraman 2022]。

在阅读本书的过程中，请不断思考这个问题：网络设计者能做些什么来防御 DoS 攻击？我们将会看到，针对三类 DoS 攻击需要不同的防御手段。

## 分组嗅探：坏人可窃听分组

今天许多用户通过无线设备上网，例如连 WiFi 的笔记本电脑，或带蜂窝连接的掌上设备（第 7 章讨论）。无处不在的因特网接入极其方便，也为移动用户带来了奇妙的新应用，但同时也造成一个重大安全弱点——只要把一个**被动接收器**放在无线发送器附近，该接收器就能获得所传输的每一个分组的副本！这些分组可能包含各种敏感信息，包括口令、社会安全号、商业秘密和私人消息。记录每一个飞过分组的副本的被动接收器，称为**分组嗅探器**（packet sniffer）。

嗅探器也能部署在有线环境中。在有线广播环境中（如许多以太网局域网），分组嗅探器可以获取局域网上发送的广播分组的副本。如 1.2 节所述，电缆接入技术也广播分组，因而同样易被嗅探。此外，若坏人得以接入某机构的接入路由器或接入链路，他可能植入嗅探器，复制进出该机构的每一个分组。被嗅探到的分组随后可离线分析，以提取敏感信息。

分组嗅探软件在各网站可免费获得，也有商业产品出售。据我们所知，有些教授在讲授网络课程时会布置实验作业，要求学生编写一个分组嗅探与应用层数据重建程序。事实上，与本书配套的 Wireshark [Wireshark 2025] 实验（见本章末的 Wireshark 入门实验）用的正是这样一个分组嗅探器！

由于分组嗅探器是被动的——即它不向信道中注入分组——因此难以检测。所以，当我们把分组送入无线信道时，必须接受一种可能性：某个坏人可能正在记录我们分组的副本。你可能已经猜到，对付分组嗅探的一些最好办法涉及**密码学**。第 8 章将讨论密码学在网络安全性方面的应用。

## 伪装：坏人可冒充你信任的人

制造一个具有任意源地址、任意内容和任意目的地址的分组，再把这个手工构造的分组发送到因特网中，让它忠实地被转发到目的地——这件事出奇地容易（随着本书的推进，你很快就会具备这样的知识！）。设想毫无戒心的接收方（比如一台因特网路由器）收到这样一个分组，把（虚假的）源地址当作真实地址，然后执行分组内容中嵌入的某个命令（比如修改自己的转发表）。这种用虚假源地址向因特网注入分组的能力称为 **IP 欺骗**（IP spoofing），它只是一个用户冒充另一个用户的众多方式之一。

要解决这个问题，我们需要**端点鉴别**（end-point authentication），即一种能让我们确信某条报文确实来自它所声称之处发源的机制。同样鼓励你在阅读本书各章时思考：对网络应用和协议而言，这该如何做到？第 8 章将探讨端点鉴别的机制。

在结束本节时，值得想一想：因特网当初怎么会变成这样一个不安全的地方？答案实质上是：因特网最初就是按"一群互相信任的用户连接在一个透明网络上"的模型设计的 [Blumenthal 2001]——在这个模型中（按定义）根本不需要安全。原始因特网体系结构的许多方面都深深反映了这种互信观念。例如，一个用户能向任何其他用户发送分组，这是默认能力，而不是需要申请/授予的能力；用户身份按其自报值采信，而不是默认加以鉴别。

但今天的因特网显然并不涉及"互相信任的用户"。尽管如此，今天的用户仍然需要在彼此未必信任的情况下通信：他们可能希望匿名通信，可能通过第三方间接通信（例如第 2 章将研究的 Web 缓存，或第 7 章将研究的移动性辅助代理），还可能不信任他们通信所依赖的硬件、软件乃至空气。随着本书的推进，我们面前有许多与安全相关的挑战：我们应当寻求针对嗅探、端点伪装、中间人攻击、DDoS 攻击、恶意软件等的防御手段。我们应当牢记：互相信任的用户之间的通信是例外，而不是常规。欢迎来到现代计算机网络的世界！
