# 1.7　计算机网络与因特网的历史

1.1 至 1.6 节概览了计算机网络与因特网的技术。读到这里，你掌握的知识已足以在亲友面前露一手了！不过，若真想在下一次聚会上大放异彩，不妨在谈话中掺入一些关于因特网迷人历史的花絮 [Segaller 1998]。

## 1.7.1　分组交换的诞生：1961—1972

计算机网络领域与今天的因特网可追溯到 20 世纪 60 年代初，当时电话网是世界上占主导地位的通信网络。如 1.3 节所述，电话网用电路交换在发送方与接收方之间传送信息——考虑到语音在收发双方之间是以恒定速率传输的，这是个恰当的选择。60 年代初计算机日益重要，分时计算机出现，人们自然会考虑如何把计算机连接起来，以便在地理上分散的用户之间共享。这类用户产生的流量很可能是**突发式**的：一段时间有活动（例如向远程计算机发送一条命令），随后一段静默（等待回应或思考收到的响应）。

当时世界上有三个研究组在彼此不知情的情况下 [Leiner 1998]，开始把分组交换发明为电路交换的一种高效而健壮的替代方案。最早发表分组交换技术工作的是当时麻省理工学院的研究生 Leonard Kleinrock [Kleinrock 1961; Kleinrock 1964]；他运用排队论，优雅地证明了分组交换方法对突发式流量源的有效性。1964 年，兰德研究所的 Paul Baran [Baran 1964] 开始研究用分组交换在军用网络上传输保密语音；在英国国家物理实验室，Donald Davies 和 Roger Scantlebury 也在发展他们关于分组交换的想法。

MIT、兰德和 NPL 的工作为今天的因特网奠定了基础。但因特网还有一段"先造出来、再演示给人看"的悠久传统，这同样可以追溯到 60 年代。Kleinrock 在 MIT 的同事 J. C. R. Licklider [DEC 1990] 和 Lawrence Roberts 先后领导了美国**高级研究计划局**（ARPA）的计算机科学计划。Roberts 发表了 ARPAnet 的总体方案 [Roberts 1967]——ARPAnet 是第一个分组交换计算机网络，也是今天公共因特网的直系祖先。1969 年劳动节，第一台分组交换机在 Kleinrock 指导下安装于 UCLA；此后不久，又在斯坦福研究所（SRI）、加州大学圣巴巴拉分校和犹他大学安装了另外三台分组交换机（图 1.27）。到 1969 年底，这个因特网的襁褓前身已有四个节点。Kleinrock 回忆说，网络的第一次使用是从 UCLA 远程登录到 SRI，结果把系统弄崩了 [Kleinrock 2004]。

到 1972 年，ARPAnet 已发展到约 15 个节点，并由 Robert Kahn 作了首次公开演示。ARPAnet 端系统之间的第一个主机到主机协议——网络控制协议（NCP）——也已完成 [RFC 001]。有了端到端协议，就可以编写应用了：1972 年，Ray Tomlinson 写出了第一个电子邮件程序。

## 1.7.2　专用网络与网络互连：1972—1980

最初的 ARPAnet 是一个单一的封闭网络，要与 ARPAnet 主机通信，必须实际连接到另一台 ARPAnet IMP 上。70 年代初中期，除 ARPAnet 之外又出现了若干独立的的分组交换网：连接夏威夷各岛大学的微波网络 ALOHANet [Abramson 1970]，DARPA 的分组卫星网 [RFC 829] 与分组无线电网 [Kahn 1978]；基于 ARPAnet 技术的 BBN 商用分组交换网 Telenet；由 Louis Pouzin 开创的法国分组交换网 Cyclades [Think 2012]；60 年代末 70 年代初的分时网络，如 Tymnet 和 GE 信息服务网 [Schwartz 1977]；以及 IBM 的 SNA（1969—1974），它与 ARPAnet 的工作并行 [Schwartz 1977]。

网络数量在不断增长。事后看来，为把这些网络连接起来而发展一个包罗万象的体系结构，时机已经成熟。在**国防高级研究计划局**（DARPA）资助下，Vinton Cerf 和 Robert Kahn 完成了互连网络的开拓性工作，实质上创造了"网络的网络" [Cerf 1974]；"互联网互连"（internetting）一词正是为描述这项工作而造出来的。

这些体系结构原则体现在 TCP 中。不过早期版本的 TCP 与今天的 TCP 差别很大：早期 TCP 把"经由端系统重传的可靠按序数据交付"（这仍是今天 TCP 的一部分）与"转发功能"（今天由 IP 承担）结合在一起。对 TCP 的早期实验，加上人们认识到对分组化语音这类应用而言，一个不可靠、无流量控制的端到端运输服务很重要，最终导致把 IP 从 TCP 中分离出来，并促成 UDP 协议的开发。今天我们看到的三个关键因特网协议——TCP、UDP 和 IP——到 70 年代末在概念上都已就位。

除 DARPA 的因特网相关研究之外，还有许多重要的网络活动在进行。在夏威夷，Norman Abramson 正在开发 ALOHAnet——一个基于分组的无线电网，使夏威夷各岛的多个远程站点能够互相通信。ALOHA 协议 [Abramson 1970] 是第一个**多址访问协议**，使地理上分散的用户共享单一的广播通信媒体（一个无线电频率）。Metcalfe 和 Boggs 在 Abramson 多址访问协议工作的基础上，为有线共享广播网开发了**以太网**协议 [Metcalfe 1976]。有趣的是，他们开发以太网的动机是需要连接多台 PC、打印机和共享磁盘 [Perkins 1994]。二十五年前，在 PC 革命和网络大爆发之前很久，Metcalfe 和 Boggs 就在为今天的 PC 局域网奠定基础了。

## 1.7.3　网络的激增：1980—1990

到 70 年代末，约有 200 台主机连到 ARPAnet；到 80 年代末，连到公共因特网（一个与今天因特网颇为相似的网络联合体）的主机数达到十万台。80 年代是大发展的十年。

这种增长很大程度源于若干把大学连接起来的独立努力。BITNET 在东北部若干大学之间提供电子邮件和文件传输；CSNET（计算机科学网）把无法访问 ARPAnet 的大学研究者连接起来；1986 年创建 NSFNET，为受 NSF 资助的超级计算中心提供接入。NSFNET 骨干网最初速度为 56 kbps，到 80 年代末已运行在 1.5 Mbps，并成为连接各区域网的主要骨干。

在 ARPAnet 共同体中，今天因特网体系结构的许多最后拼图正各就各位。1983 年 1 月 1 日，TCP/IP 被正式部署为 ARPAnet 的新标准主机协议（取代 NCP）。从 NCP 到 TCP/IP 的转换 [RFC 801] 是一次"旗帜日"事件——从那天起所有主机都必须转到 TCP/IP。80 年代后期，TCP 被作了重要扩展以实现基于主机的拥塞控制 [Jacobson 1988]；用于在人类可读的因特网名字（例如 gaia.cs.umass.edu）与其 32 比特 IP 地址之间进行映射的 DNS 也发展了起来 [RFC 1034]。

与 ARPAnet 的发展（这基本上是美国的努力）并行，法国在 80 年代初启动了 Minitel 计划——一个把数据网络带进每个家庭的雄心勃勃的方案。Minitel 系统由政府资助，由公共分组交换网（基于 X.25 协议族）、Minitel 服务器以及内置低速调制解调器的廉价终端构成。1984 年，法国政府向每个愿意要的法国居民家庭免费发放一台 Minitel 终端，Minitel 由此大获成功。Minitel 站点既有免费站点（如电话号码簿），也有向用户按使用量收费的私有站点。在 90 年代中期的巅峰时期，它提供两万多种服务，从家庭银行到专业研究数据库。在大多数美国人还没听说过因特网之前十年，Minitel 就已进入很大一部分法国家庭。

## 1.7.4　因特网大爆炸：20 世纪 90 年代

90 年代在一系列事件中拉开帷幕，这些事件象征着因特网的持续演进和即将到来的商业化：因特网的祖先 ARPAnet 停止存在；1991 年，NSFNET 取消了对其商业用途的限制；NSFNET 本身于 1995 年退役，因特网骨干流量由商业因特网服务提供商承载。

90 年代的主要事件是万维网应用的出现，它把因特网带进了全世界数以百万计的家庭和企业。Web 成为一个平台，催生并部署了数百个今天我们习以为常的新应用，包括搜索（如 Google、Bing）、因特网商务（如 Amazon、eBay）和社交网络（如 Facebook）。

Web 由 Tim Berners-Lee 于 1989 至 1991 年间在 CERN 发明 [Berners-Lee 1989]，其思想源自 Vannevar Bush 在 40 年代 [Bush 1945]、Ted Nelson 自 60 年代以来 [Xanadu 2012] 关于超文本的早期工作。Berners-Lee 及其同事开发了 HTML、HTTP、Web 服务器和浏览器的最初版本——Web 的四个关键组件。1993 年底前后，约有 200 台 Web 服务器在运行，这批服务器只是即将到来之浪潮的先声。大约同时，若干研究者正在开发带图形界面的浏览器，其中包括 Marc Andreessen——他与 Jim Clark 一起创办了 Mosaic Communications，即后来的 Netscape Communications 公司 [Cusumano 1998; Quittner 1998]。到 1995 年，大学生已每天用 Netscape 浏览器上网冲浪；大约同时，大大小小的公司开始运行 Web 服务器并在 Web 上进行交易。1996 年微软开始做浏览器，引发 Netscape 与微软的浏览器之战，几年后微软胜出 [Cusumano 1998]。

90 年代后半期是因特网大发展、大创新的时期，大公司和成千上万家创业公司创造了大量因特网产品与服务。到千年之交，因特网已支撑数百个流行应用，其中包括四个"杀手级应用"：

- 电子邮件，包括附件与可经 Web 访问的邮件；
- Web，包括网页浏览与因特网商务；
- 即时消息，带联系人列表；
- MP3 的点对点文件共享，由 Napster 开创。

有趣的是，前两个杀手级应用来自研究界，后两个则由几位年轻的创业者创造。

1995 至 2001 年，因特网在金融市场上经历了一轮过山车。数百家因特网创业公司在尚未盈利时就首次公开募股、开始在股市交易，许多公司在没有任何可观收入来源的情况下被估值数十亿美元。2000—2001 年因特网股票崩盘，许多创业公司关门。尽管如此，仍有一批公司在因特网领域成为大赢家，包括微软、思科、雅虎、eBay、Google 和亚马逊。

## 1.7.5　新千年

在 21 世纪的头三十年里，也许没有哪项技术比因特网以及联网的智能手机更深刻地改变了社会。而计算机网络的创新仍在继续：更快的路由器、接入网与骨干网中更高的传输速率等各方面都在进步。以下发展尤其值得关注：

::: tip 要点

+ **宽带接入大举进入家庭。** 自千年之交以来，家庭宽带接入被大规模部署——不仅有电缆调制解调器和 DSL，还有 1.2 节讨论的光纤到户、5G 固定无线和 LEO 卫星。这种高速接入催生了大量视频应用，包括用户生成视频的分发（如 YouTube、TikTok）、高清电影与电视剧的点播流媒体（如 Netflix）以及多人视频会议（如 Zoom、FaceTime、Google Hangouts）。
  + **高速无线接入日益普及。** 它不仅让人们在移动中保持持续连接，还催生了新的基于位置的应用，包括导航与地图（如 Google 地图、Waze）、网约车（如 Uber、滴滴）、外卖配送、本地商户搜索和婚恋服务（如 Tinder）。2011 年，接入因特网的无线设备数量超过了有线设备。这种高速无线接入为手持计算机（iPhone、Android、iPad 等）的迅速崛起铺平了道路，它们可以持续、无拘无束地接入因特网。
  + **在线社交网络。** Facebook、Instagram、Twitter、TikTok 和微信（在中国极受欢迎）等社交网络在因特网之上构建了庞大的人际网络。其中许多既被大量用于发消息，也用于分享照片和视频。今天许多因特网用户主要"生活"在一个或多个社交网络之中。通过各自的 API，在线社交网络为新形态的联网应用（包括移动支付和分布式游戏）搭建了平台。
  + **内容提供商自建专用网络。** 如 1.3.3 节所述，Google、微软等在线服务提供商部署了自己庞大的专用网络，不仅把其全球分布的数据中心连接起来，还通过与较低层 ISP 直接对等来尽可能绕过因特网。结果是，Google 能以几乎瞬时的速度提供搜索结果和邮件访问，仿佛其数据中心就运行在你自己的计算机里。
  + **应用上云。** 许多因特网商务公司现在把应用运行在"云"上——如 Amazon EC2、微软 Azure 或阿里云。许多公司和大学也把其因特网应用（如邮件和 Web 托管）迁移到云端。云服务公司不仅为应用提供可扩展的计算与存储环境，还让应用隐式地获得了它们高性能专用网络的接入能力。
