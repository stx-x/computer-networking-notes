网络应用是计算机网络存在的理由——如果我们想不出任何有用的应用，也就不需要网络基础设施和支撑它们的协议了。自因特网诞生以来，确实产生了许多有用而有趣的应用。这些应用一直是因特网成功的驱动力，被家庭、汽车、学校、政府和企业中的人们使用，使因特网成为他们日常活动中不可或缺的一部分。

因特网应用包括 20 世纪 70、80 年代流行起来的经典文本类应用：文本电子邮件、远程计算机访问、文件传输和新闻组；也包括 90 年代中期的杀手级应用——万维网，涵盖网页浏览、搜索和电子商务。进入新千年以来，新的、极具吸引力的应用不断涌现，包括 Zoom、FaceTime、Teams 这样的视频会议，YouTube 这样的用户生成视频，Netflix 这样的点播电影，以及《第二人生》《魔兽世界》这样的多人在线游戏。同一时期，还出现了新一代社交网络应用——TikTok、Facebook、Instagram、X 等——它们在因特网的路由器与通信链路之上构建起了人际网络。最近，随着智能手机的到来和 4G/5G 无线接入的普及，基于位置的移动应用大量涌现，包括流行的签到、交友和路况预测应用（如 Yelp、Tinder、Waze）、移动支付应用（如微信、Apple Pay）和消息应用（如微信、WhatsApp）。显然，新的精彩因特网应用从未放慢脚步。也许本书的某些读者，就会创造出下一代的杀手级因特网应用！

本章研究网络应用的概念与实现两个方面。我们先定义关键的应用层概念，包括应用所需的网络服务、客户与服务器、进程以及运输层接口；然后详细考察若干网络应用，包括 Web、电子邮件、DNS 和视频流；接着讨论基于 TCP 与 UDP 的网络应用开发，特别是套接字接口，并用 Python 走一遍几个简单的客户-服务器应用。本章末还提供了若干有趣味的套接字编程作业。

应用层是开始学习协议的绝佳起点：这是熟悉的地带，我们对依赖这些协议运行的许多应用并不陌生；它能让我们很好地体会"协议到底是怎么回事"，并让我们预先接触到那些在学习运输层、网络层和链路层协议时会再次遇到的问题。
