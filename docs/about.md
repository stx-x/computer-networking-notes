# 关于这份讲义

这份站点是《Computer Networking: A Top-Down Approach》（Kurose & Ross，第 9 版）的中文逐节译注，原本是排给内部阅读的 PDF 讲义（B5、约 740 页），现在整理成网页版，方便检索与留档。

## 它是什么，不是什么

**是**：按原书段落顺序的完整翻译，保留全部插图、表格与公式推导。每个协议的端口号、首部字段长度、超时门限这类数字都在正文里就地给出，末尾另附速查表。

**不是**：不是读书笔记，不是考点摘要，也不是对原书的替代。译注里加了一些原书没有的旁白（用「专栏」卡片标出），那些是整理者的补充说明，读的时候应当能分辨出来。

## 技术说明

- 正文与 PDF 讲义同源，由 Typst 源码自动转换而来，公式统一转为 LaTeX 由 MathJax 渲染。
- 插图取自原书，按原编号命名（`fig8-29.png` 即图 8.29）。
- 站点用 VitePress 构建，静态托管于 GitHub Pages，支持全文搜索与深浅色主题。
