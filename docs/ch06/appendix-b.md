# 附录 B　数值与帧格式速查

| **项目** | **数值** | **说明** |
| --- | --- | --- |
| MAC 地址长度 | 6 字节 / 48 比特 | 十六进制书写，如 `49-BD-D2-C7-56-2A` |
| 地址空间 | MAC $2^{48}$ | IEEE 按前 24 比特分配 |
|  | IPv4 $2^{32}$ | 对照：IPv6 为 $2^{128}$ |
| MAC 广播地址 | FF-FF-FF-FF-FF-FF | 48 个连续 1 |
| ARP 表项生存期 | 典型 20 分钟 | 过期即删除 |
| 以太网数据字段 | 46–1 500 字节 | MTU 1 500；不足 46 需填充 |
| 前同步码 | 8 字节 | 7 × `10101010` + `10101011` |
| 以太网首部 + CRC | 14 + 4 字节 | 目的 6 + 源 6 + 类型 2 + CRC 4 |
| 802.1Q 标签 | 4 字节 | TPID `81-00` + TCI；12 比特 ID |
| VXLAN VNI | 24 比特 | 1 600 万个 VXLAN（突破 4 096） |
| MPLS 首部 | 4 字节 | 标签 + 3 比特实验 + S 比特 + TTL |

| **协议／机制** | **效率或参数** | **备注** |
| --- | --- | --- |
| 时隙 ALOHA | $\frac{1}{e} \approx 0.37$ | 成功 37%、空 37%、冲突 26% |
| 纯 ALOHA | $\frac{1}{2 e} \approx 0.18$ | 完全分散的代价 |
| CSMA/CD | $\frac{1}{1 + 5 \frac{d_{\text{prop}}}{d_{\text{trans}}}}$ | $d_{\text{prop}} \to 0$ 时趋于 1 |
| 以太网退避 | $K \cdot 512$ 比特时间 | $K$ 取自 ${0, \cdots, 2^{n} - 1}$，$n$ 上限 10 |
| 512 比特时间 | 5.12 微秒 | 10 Mbit/s 以太网上的退避粒度 |
| 交换机老化时间 | 典型 60 分钟 | 无帧则删除表项 |
| CRC 突发检测 | $\le r$ 比特必检 | $> r + 1$ 比特：概率 $1 - 0.5^{r}$ |

最后把本章出现的互联设备按"工作层次—转发依据"并列对照。"工作层次"决定了设备能看到哪些首部字段，也决定了它的转发依据与隔离能力——这也是"交换机与路由器有何不同"这类问题的标准答法。

| **互联设备** | **工作层次与转发依据** |
| --- | --- |
| 中继器 / 集线器 | 物理层，逐比特再生并转发到所有其他端口 |
| 链路层交换机 | 第 2 层，按目的 MAC 地址查交换机表转发 |
| 路由器 | 第 3 层，按目的 IP 地址做最长前缀匹配转发 |
| 负载均衡器（"四层交换机"） | 按目的端口号 + 目的 IP 地址做分发决策 |
| VLAN 交换机 | 第 2 层，按端口所属 VLAN 隔离广播域 |
